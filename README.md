# Toronto Drop-In Sports Tracker

**Live site:** [torontodropin.ca](https://torontodropin.ca)

A simple web app for finding drop-in sports at Toronto community centres. Pick a sport and a day, allow your location (or enter an address), and see nearby sessions sorted by distance — no account required.

## What it does

- Shows drop-in times for sports like badminton, basketball, volleyball, pickleball, swimming, and more
- Sorts centres **nearest to you** within 30 km using browser location, with an optional address or postal code override
- Lets you **star favourite centres** so they stay pinned at the top of the list
- Switches between **this week** and **next week**, with day-of-week and sport filters
- Displays session times, age groups, and availability when the city publishes it

## Data

Schedule information comes from public City of Toronto recreation feeds — the [drop-in sports map](https://www.toronto.ca/explore-enjoy/parks-recreation/program-activities/sports/drop-in-sports-map/) and each centre’s facility schedule. This is an independent project, not affiliated with the City of Toronto. Always confirm times on [toronto.ca](https://www.toronto.ca) before you go.
